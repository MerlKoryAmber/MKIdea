# LinuxOps Web

Веб-сервис для управления парком Linux и доступа к серверам через браузер, с записью и аудитом. Ставится на одну ВМ AlmaLinux / RHEL. Работает на том же ядре, что настольный LinuxOps (`src/LinuxOps.Core`).

## Что умеет

- **Inventory** — хосты и папки, секреты SSH в зашифрованном хранилище.
- **Actions** — каталог действий:
  - опрос и dry-run;
  - «Применить» — с замком хоста на время действия;
  - «Версии ПО» и CVE: что закрыть сейчас.
- **Vulnerabilities** — сводка по всем хостам: версии ПО, CVE, обновления безопасности. Проверка по расписанию.
- **Connections** — терминал SSH и RDP через guacd. Сеансы пишутся, запись проигрывается в History.
- **SSH Files** — SFTP в браузере.
- **PowerShell** — консоль pwsh с PowerCLI на сервере. Только «Админ».
- **History** — история действий, аудит, сеансы.
- **Вход:**
  - AD (LDAPS) со вторым фактором MK 2FA;
  - локальные пользователи и локальный админ с TOTP.
- **Права** — как в vSphere: роль (набор прав) → кто → на что (всё, папка, хост).
- **API только на чтение** — внешние сервисы по токену запускают информационные действия.

## Сборка релиза

```powershell
.\tools\package-linuxops-web.ps1
```

Скрипт сначала проверяет зависимости:
- уязвимые NuGet-пакеты — если найдены, сборка останавливается;
- свежесть .NET внутри сборки;
- контрольную сумму guacamole.

Затем собирает `dist\LinuxOps.Web-<версия>-linux-x64.tar.gz` и файл `.sha256` к нему. С ключом `-Publish` (только по запросу) кладёт их ещё и в `releases/linuxops-web` (Git LFS) вместе с `LATEST`: оттуда сервер ставится одной командой (`deploy/get.sh`) и обновляется из меню.

Выкладка на стенд лабы: `tools\deploy-linuxops-web.ps1 -Target stand`.
