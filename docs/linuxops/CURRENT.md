# LinuxOps — CURRENT

**Версия:** 0.3.27

## 0.3.27
- Каталог действий: одно состояние вместо двух. Выделения карточек больше нет — рамка и подсветка значат только «в плане». Щелчок по любому месту карточки ставит или снимает галку, двойной щелчок — «Изменить» (галка не меняется).
- «Изменить», «Клонировать», «Удалить» — значки на карточке (ярче при наведении) и правая кнопка мыши. У встроенных корзины нет, в меню «Удалить» неактивно. Над каталогом осталась только «Новое».

## 0.3.26
- Вкладки сессий в SSH Terminal и SSH Files: несколько хостов одновременно, у каждой вкладки своё соединение (терминал — свой экран и PTY; файлы — свои папки, правки F4, передачи и режим sudo). Список хостов слева общий.
- Двойной щелчок или Enter по хосту: уже открыт — переход на его вкладку (закрытую сессию терминала — переподключить), иначе новая вкладка. В SSH Files пустая вкладка подключается сама. Ещё одна сессия к тому же хосту — «Новая вкладка с этим хостом» в меню хоста, «Дублировать сессию» в меню вкладки или Ctrl+Shift+T. Номер у второй и следующих: «lab-centos (2)».
- На вкладке точка состояния (зелёная — подключено, жёлтая — подключение или передача), подсказка с адресом и папкой. Закрыть — ×, средняя кнопка мыши, Ctrl+Shift+W или «Закрыть остальные»; живую сессию терминала — после вопроса, файлы — с проверкой несохранённых правок F4 и идущей передачи. Ctrl+Tab / Ctrl+Shift+Tab — по кругу, Ctrl+T в SSH Files — пустая вкладка. Последняя вкладка SSH Files заменяется пустой.
- F9 / «Терминал здесь» открывает новую вкладку терминала сразу в текущей папке, не трогая уже открытые сессии. Кнопка «SSH Files» в терминале — этот хост в файлах.
- Последняя папка хоста общая для всех вкладок. Счётчик «папок N, файлов M» обновляется после каждой загрузки списка (раньше оставался 0 до щелчка).
- Проверено на лабе: две вкладки терминала с разным выводом, Ctrl+Tab, повторное открытие хоста переходит на вкладку, закрытие с вопросом, две вкладки файлов, F9 — новая вкладка с `cd`.

## 0.3.24
- SSH Terminal и SSH Files: список хостов слева с поиском (имя, адрес, пользователь). Двойной щелчок или Enter — подключиться. Меню хоста: открыть в соседней вкладке.
- Терминал: пароль sudo больше не уходит сам. Только на «[sudo] password for <логин хоста>:» и только после подтверждения; на запросы ssh, passwd, mysql ничего не отправляется. Размер PTY по окну, альтернативный экран (less, vim, mc), область прокрутки, вставка и удаление символов, режим стрелок приложения. Esc, Ctrl+буквы, Alt+буквы, PgUp/PgDn, F1–F12, Ctrl+Shift+C/V. Закрытие сессии (`exit`, обрыв) видно сразу.
- F4: временные копии в /tmp — 600 и владелец пользователь SSH, удаляются (раньше 644 от root и оставались). Запись на место (`cat` / SFTP с обрезкой), а не переименование: ссылки, inode, владелец и метки SELinux целы. Резервная копия — в `~/.linuxops-bak/<путь>.<время>` с правами оригинала, не рядом с файлом (рядом её подхватили бы cron.d и logrotate.d). sudoers всегда через `visudo -cf`, даже под root. Закрытие редактора с «Не сейчас» правку не теряет; редактор, передавший файл открытому окну, правку не закрывает. У правки кнопки «Сохранить» и «Закрыть».
- Исправлено: права через SSH.NET задавались битами вместо восьмеричных цифр (0644 превращалось в 0420).
- SSH Files ближе к WinSCP: папки копируются целиком в обе стороны, вопрос «Заменить / Пропустить / … все», прогресс и «Отмена». Колонки «Права» и «Владелец» (имена из getent), сортировка по щелчку на заголовке, скрытые файлы (Ctrl+H), ссылки на папки открываются. Контекстное меню, «Свойства и права» (chmod/chown, рекурсивно), новый файл (Shift+F4), перенос через F6 с путём, копировать путь, F9 — терминал в текущей папке. Enter, Backspace, Tab, Del, Alt+←/→. Режим sudo: если своих прав не хватает — то же от root. Удаление локальных файлов — в корзину; системные каталоги целиком не удаляются.
- Проверено на лабе (CentOS Stream 9, SELinux enforcing): 40 автоматических проверок (root и обычный пользователь с sudo) и вручную в окне — подключение двойным щелчком, `top`, загрузка и скачивание папки с заменой, F4 в Блокноте с Ctrl+S три раза, свойства, удаление, F9.

## 0.3.21
- F4 открывает файл в программе из настройки «Редактор для F4» (по умолчанию notepad.exe). Копия в `%TEMP%\LinuxOpsEdit`. Несколько файлов сразу, у каждой «Закрыть правку».
- После сохранения — вопрос «Сохранить … на …?». Неизменённый файл не грузится. Если на сервере другие размер или время — предупреждение. Запись: либо переименование `.linuxops.tmp` с прежними правами, либо через sudo `cp` в `.bak` и `cat` на место. Для sudoers перед заменой `visudo -cf`.



## 0.3.20
