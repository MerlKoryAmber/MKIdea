# LinuxOps — CURRENT

**Версия:** 0.3.15

## 0.3.15
- Пароль sudo подаётся только после `sudo -n true`, если sudo его просит. NOPASSWD больше не исполняет пароль как команду и не пишет его в журнал.
- Добавление пользователя: ошибка шага останавливает скрипт с текстом, без зелёного «создан». Каталог ключа — группа `id -gn`. На SUSE sudo пишется в `/etc/sudoers.d`, не в wheel.
- Кэш пароля sudo — потокобезопасный. «Стоп» шлёт отмену в уже запущенную SSH-команду.
- Футер только на Actions. Линия таблицы Inventory — цвет темы, без чёрной рамки строки. Списки свои. Шапка SSH Files слева и справа одной высоты.

## 0.3.14
- SSH Files: список, загрузка, скачивание и удаление не на потоке окна, прогресс в строке. Путь правится, Enter переходит, есть назад/вперёд. Несколько файлов, перетаскивание между панелями и из проводника. F4 на удалённом: скачать во временный файл, править, спросить «Загрузить обратно?».

## 0.3.13
- «Добавить пользователя» в шапке хостов. Логин, sudo, открытый ключ (файл), пароль по желанию. Значения в скрипт через переменные stdin, не в argv. Повторный запуск не плодит ключ. Строка вида «хост — уже был, ключ добавлен». Встроенный `ensure-user-demo` удалён.

## 0.3.12
- Хосты плана идут параллельно, не больше 4. Статус «хост N из M», отмена между хостами. «Проверить обновления» в строке — число пакетов и security, полный вывод в деталях. Кнопка «Копировать».

## 0.3.11
- «В плане» — галочка на карточке, пишется в `SelectedActionIds`. Выделение карточки одно и только для Изменить/Клон/Удалить. До запуска справа предпросмотр: хост × действие и пропуск по дистрибутиву.

## 0.3.10

## 0.3.9

## 0.3.8
- Пароли хостов в defaults — DPAPI (`dpapi:`). Старый открытый текст читается и шифруется при следующем сохранении.

- В карточке хоста: «Обзор…» ключа и «Проверить подключение».

## 0.3.7
- Dry-run «Установить обновления» — симуляция (`apt-get -s`, `dnf --assumeno`, `zypper --dry-run`). Прочие destructive в dry-run: «скрипт не выполнялся». «Применить» спрашивает подтверждение со списком хостов.

## 0.3.6
