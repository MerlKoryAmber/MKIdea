# LinuxOps Web 0.7.3 — отчёт

Дата: 22.11.2026. Стенд: 192.168.0.169, версия 0.7.3, Health OK.

## Что сделано

1. **Смена своего пароля в интерфейсе.** Щелчок по имени в шапке. Нужны текущий пароль, новый (от 12 символов, дважды) и код TOTP. Доступно локальным пользователям и локальному админу с подтверждённым TOTP. В лабораторном режиме админу — отказ с отсылкой к меню на сервере. Пауза после 5 неудач за 15 минут общая со входом. Аудит: «пароль: сменён сам» / «пароль: отказ».
2. **Сборки в репозитории, как у MK Adm.** `releases/linuxops-web` в ветке `feature/linuxops-web`: архив через Git LFS, `.sha256`, `LATEST`, хранятся 5 последних версий. Кладёт их скрипт сборки **только с ключом `-Publish`** (по запросу владельца). Обычная сборка и выкладка на стенд туда не пишут. В этой версии в `releases` ничего не выложено.
2a. **Привязка TOTP:** кроме QR — ключ и строка `otpauth://` для хранилищ паролей, кнопки «Копировать». Если браузер не даёт доступ к буферу — запасной способ, иначе подсказка.
3. **Установка одной командой** — `deploy/get.sh`: читает `LATEST`, качает архив, сверяет сумму, запускает `install.sh`. Ключи `--version`, `--check`, свой источник и токен — через окружение. На уже установленном сервере отказывает.
4. **Обновление из меню** берёт сборки оттуда же (`PROVIDER=repo`, `RAW_BASE`). Старый `release.conf` переписывается сам, копия — `release.conf.bak`.
5. Подсказка у нового локального пользователя: куда идти за ролью.
6. Документы: INSTALL (переписан), README, CURRENT, SKELETON, PLAN-web.
