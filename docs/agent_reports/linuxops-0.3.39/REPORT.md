# LinuxOps 0.3.39 — vCenter в Inventory, папки и дерево ресурсов

Дата: 2026-11-12 (МСК).

## Задача
Подключение к vSphere — через общий Inventory, а не через отдельные профили на вкладке PowerShell. Папки для ресурсов: перетаскивание мышью, сворачивание.

Согласовано (развилки, все — рекомендованные): вложенные папки без ограничения; дерево везде, где есть список хостов; пароль vCenter только в памяти; PowerShell-действие — на каждом отмеченном vCenter по очереди.

## Изменения
- `Models/AppModels.cs`: `IInventoryItem` (общее для `HostConfig` и `VCenterProfile`), `HostFolder`, `FolderId` у ресурсов, `AppDefaults.Folders`; у `VCenterProfile` — `IsSelected`, `Status`, значок «vC».
- `ViewModels/AppSession.cs`: `VCenters`, `Folders`, `TreeChanged`, операции с папками (создать, удалить с переездом содержимого, перенести с запретом цикла), чистка ссылок на несуществующие папки.
- `Services/DefaultsStore.cs`: `SaveInventory` (хосты + vCenter + папки) вместо `SaveHosts`/`SaveVCenters`.
- `ViewModels/InventoryTree.cs` + `Views/ResourceTree.xaml(.cs)` — одно дерево на все вкладки: шаблон под темы, галочки (три состояния у папки), перетаскивание с подсветкой цели и автопрокруткой, поиск, сохранение свёрнутости.
- `Views/InventoryView`, `ViewModels/InventoryViewModel`, `ViewModels/HostDialogs`, `VCenterEditWindow` (новое), `AppDialog.AskText`, `HostEditWindow` (сохраняет папку).
- `Views/ActionsView`, `ViewModels/ActionsViewModel`: дерево с галочками, PowerShell на отмеченных vCenter, «Опросить» vCenter (порт 443), пересчёт выбора один раз после галочки папки.
- `Views/HostListPanel` (SSH Files, Terminal): дерево без vCenter, поиск, меню только у хоста.
- `PsRunWindow` — только параметры; `VsphereWindow` — только модули.

## ✅ Проверено
Копия программы в scratchpad, копия тестовых данных (хосты лабы + профиль vCenter из 0.3.38), UI Automation, мышь — только при переднем плане окна копии. Тёмная и светлая темы.
- Профиль vCenter из 0.3.38 появился в Inventory без правки JSON.
- «+ Папка» в корне и внутри выделенной; перетаскивание мышью: хост → вложенная папка, vCenter → папка (JSON: FolderId верные).
- Папку «Лаба» в её же вложенную «Linux» перенести нельзя — ничего не меняется.
- «+ vCenter» при выделенной папке — попадает в неё.
- Сворачивание треугольником: дети скрыты, `IsExpanded=false` в JSON; разворачивание.
- Actions: галочка папки снимает и ставит всё внутри; снятие одного vCenter — у папки «частично», обратно — «вкл». Сводка «→ 1 хост и 2 vCenter».
- Dry-run: окно параметров, затем вход в 127.0.0.1 и в 127.0.0.2 по очереди (отменены), строки FAIL «вход в vCenter … отменён» для каждого, записи в History.
- SSH Terminal и SSH Files: дерево без vCenter; поиск «sudo» → один хост, «zzz» → «Ничего не найдено», очистка → всё.
- Удаление папки «Linux»: подтверждение, хост переехал в «Лаба»; переименование «Лаба» → «Лаборатория»; после перезапуска всё на месте.
- Сборка Debug и Release (dist) без ошибок; dist запускается.

- Работа против настоящего vCenter 8 — стенда нет (как и раньше).
- Ревью не автором не проводилось.
