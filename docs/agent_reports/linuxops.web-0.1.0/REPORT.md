# LinuxOps Web 0.1.0 — первый веб на общем ядре

Дата: 2026-11-21 (МСК). Ветка `feature/linuxops-web`, в master не влито.

## Задача
- Владелец: «делай ветку — и всё, что можно без стенда; внешне веб должен быть максимально идентичен с настольной версией». В лабе решение ИБ не нужно.
- По плану `docs/linuxops/PLAN-web.md` это Ф1 (ядро), Ф2 (основа сервиса) и Ф2+ («Версии ПО», CVE, «Обновить отмеченное»). Ф0 (стенд) и Ф3 (guacd) ждут ВМ.

## Решение
- **Ядро `src/LinuxOps.Core`** (net8.0) — 22 файла сервисов и модели перенесены из настольной версии через `git mv`; настольная 0.3.54 работает на нём (`docs/agent_reports/linuxops-0.3.54`).
- **Сервис `src/LinuxOps.Web`** — Blazor Server, одна страница, вид настольной версии:
  - шапка с градиентом и вкладками, подвал с планом и кнопками;
  - Actions в три колонки: хосты с папками и галками, карточки каталога, тёмная панель запуска с «Деталями»;
  - цвета обеих тем — из `Themes/Light.xaml` и `Dark.xaml`;
  - окна (Хост, Добавить пользователя, Параметры действий, Перезапуск служб, Ключ хоста, Пароль sudo) повторяют поля настольных.
- **`WebSession`** — перенос `ActionsViewModel`: строки RUN с таймером и последней строкой вывода, живой вывод в «Деталях», 5 шагов «Обновить отмеченное».
- **Вопросы ядра в браузер:** `IUserPrompts` → `WebPrompts`. Вопрос идёт в окно, запустившее действие; фоновый поток ждёт ответа.
- **Хранилище:** SQLite. Пароль и ключ шифруются AES-256-GCM; мастер-ключ хранится отдельно от базы.
- **Аудит** пишется в три места: база (только дописывание), `audit.log`, syslog.
- **Блокировка хоста** на время действия.
- **Юнит systemd** — `deploy/linuxops-web.service`.
- Что в вебе пока выключено — `docs/linuxops.web/CURRENT.md`, «Отложено».

## ✅ Проверено
**Локальный запуск на этом ПК, браузер встроенный, хост — лаба 192.168.0.178 (CentOS Stream 9).**
- **Ключ хоста.** При первом опросе пришло окно «Ключ хоста». Отпечаток совпал с `~/.ssh/known_hosts` (`SHA256:VMlj1v9x…`).
- **Опрос:** CentOS, статус online.
- **«Проверить подключение»** в окне «Хост» — «Подключено. CentOS Stream 8 (centos)». На этом IP по очереди работают две ВМ, поэтому опрос и окно «Хост» могут видеть разные.
- **Dry-run «Проверить обновления»** — 274 обновления (3 security).
- **«Версии ПО» с CVE** — «Закрыть сейчас: nginx — 1, PHP/PHP-FPM — 4», как в настольной 0.3.53. Строка RUN шла с таймером и живым выводом. Первая сверка заняла около минуты, с кэшем — 5 с. Снимок — `actions-versions-cve.jpg`.
- **«Обновить отмеченное»** (на лабе httpd понижен до 2.4.62-16):
  1. предпросмотр, 5 пакетов, подтверждение со списком (`update-confirm.jpg`);
  2. установка;
  3. окно перезапуска служб, перезапущена `vgauthd` (на лабе `ActiveEnterTimestamp` 02:37:40);
  4. повторная проверка — httpd-core 2.4.62-17.
- **«Добавить пользователя»** — `webtest` с ключом и sudo; виден в таблице «Аудит пользователей». После проверки удалён с лабы.
- **«Детали»:** карточки учёток и карточка прокси отрисовались.
- **Блокировка хоста.** Второе окно запустило действие на хосте с тем же адресом и получило «WARN … занят: 127.0.0.1, Версии ПО…, с 02:34:45».
- **History** — записи всех шагов с колонкой «Кто».
- **Аудит** — `audit.log`: опрос, проверка подключения, каждый запуск и его итог, с адресом клиента.
- **Inventory:**
  - добавить хост, удалить хост, удалить папку — работают;
  - ключ, загруженный в хранилище, в базе только как `v1:…` — текста ключа в файлах базы нет.
- **Светлая тема** — панель запуска остаётся тёмной, как в настольной (`actions-light.jpg`).
- **Linux-сборка на лабе** (CentOS 9, self-contained linux-x64; пробный запуск, потом убран):
  - страница и `app.css` отдаются (200);
  - база создалась в `/var/lib/linuxops-web`, ключ — `/etc/linuxops-web/master.key` с правами 600;
  - запись «запуск» есть в `journalctl -t linuxops-web`.
- **Сборка** всего решения — без ошибок; `tools/LinuxOpsLabCheck` поправлен (он не собирался ещё на master).
- **Найдено и исправлено при проверке:**
  - 404 без маршрутизатора;
  - кавычки в атрибутах Razor;
  - падение на двух хостах с одним адресом;
  - правая панель уезжала за край из-за широкой таблицы;
  - итог в аудите считал строки прошлых шагов;
  - статус хостов сбрасывался при смене вкладки.

## 👀 Не проверено
- **Стенд:** HTTPS, вход, файрвол, SELinux, служба под своим пользователем — нет ВМ (Ф0). Юнит службы на живой системе не запускался.
- **Пароль sudo и пароль ключа из браузера:** путь тот же, что у «Ключа хоста», но на лабе вход root по ключу без пароля — окна не появлялись.
- **Загрузка файла ключа кнопкой «Файл…»:** встроенный браузер не открывает выбор файла. Хост лабы занесён тестовой утилитой через то же хранилище, ключ через меня не проходил.
- **Несколько хостов одновременно, хосты Debian / Ubuntu** — на лабе один CentOS.
- **Внешний вид рядом с настольной:** цвета и размеры взяты из XAML, но снимки рядом не сравнивались. Шрифт Segoe UI есть только в Windows; на Linux-клиентах будет системный.
- Ревью не автором не проводилось.
