# LinuxOps Web 0.3.1 — настройки под шестерёнкой

Дата: 2026-11-21 (МСК). Ветка `feature/linuxops-web`.

## Задача
Владелец: «может ты настройки в шестерёнку перенесёшь и не будешь занимать место на экране надписью настройки?» — было два пункта «Настройки»: вкладка (вход, роли) и шестерёнка (тема).

## Решение
- Вкладка «Настройки» убрана из шапки. Шестерёнка ⚙ открывает страницу настроек и подсвечивается, пока она открыта.
- На странице сверху — тема (как в системе / светлая / тёмная): видна всем, применяется сразу, хранится в браузере. Ниже, только с правом «Настройки», — вход через AD, сессия, локальный админ, роли.
- Окно выбора темы (`DialogHost`, вид `settings`) удалено.

## ✅ Проверено
Стенд 192.168.0.169, версия 0.3.1 выложена `tools/deploy-linuxops-web.ps1`.
- `lo-dept-test` (без права «Настройки»): в шапке нет вкладки «Настройки»; шестерёнка («Настройки: тема») открывает только блок «Тема»; «Тёмная» — тема сменилась сразу и записалась в браузер; возвращено «Как в системе».
- `admin` (лабораторный режим): шестерёнка («Настройки: тема, вход, роли») — тема, вход через AD, сессия, роли на одной странице.

## 👀 Не проверено
- Ничего нового. Хвосты 0.3.0 (LDAPS/StartTLS, MK 2FA, ширина < 1080 px) остаются.
