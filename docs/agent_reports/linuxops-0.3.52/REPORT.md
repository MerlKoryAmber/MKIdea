# LinuxOps 0.3.52 — выпадающие списки той же высоты, что поля ввода

Дата: 2026-11-20 (МСК).

## Задача
Вопрос владельца по снимку окна «Хост»: «почему все поля как поля, а Auth обрезанное и буквы туда не влазят». Причина объяснена, владелец согласился исправить («Да, делай»).

## Причина
- Стиль `ComboBox` в `Themes/Theme.xaml` задаёт `Padding`, но шаблон его не использует.
- Высота нигде не задана, поэтому список был ровно в высоту текста с рамкой.
- У `TextBox` и `PasswordBox` отступ 8,4 — они около 26 px.
- В других окнах высота списков задана вручную (`Height="28"`), поэтому заметно было только в «Хосте».

## Изменения
- **`Themes/Theme.xaml`** — у стиля `ComboBox` добавлен `MinHeight` 26: как у полей ввода, для всех списков сразу.
- **`HostEditWindow.xaml`** — окно подстраивает высоту под содержимое (`SizeToContent="Height"` вместо 520). С выросшим списком кнопка «Проверить подключение» подрезалась снизу.

## ✅ Проверено
- **Окно «Хост»** (Debug, UI Automation, снимок):
  - Host, User, Password — 26 px; Auth был ниже соседей, стал 26 px;
  - сначала попробовал `MinHeight` 28 — список вышел на 2 px выше полей, исправил на 26;
  - кнопка «Проверить подключение» видна целиком.
- **Редактор действия** (снимок): списки «Тип» и «Привилегии» — 26 px, вёрстка не поехала.
- Списки с заданной вручную высотой («Закрыть доступ», «Базовые пользователи», SSH Files) не затронуты: `MinHeight` меньше их высоты.
- **Release `dist\LinuxOps-0.3.52`** (копия): версия 0.3.52, те же высоты в обоих окнах.
- Сборка Debug и Release — без ошибок.

## 👀 Не проверено
- Светлая тема — только тёмная на снимках; правка не касается цветов.
- Ревью не автором не проводилось.
