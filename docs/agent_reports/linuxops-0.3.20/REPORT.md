# 0.3.20 — SSH Terminal и панель F1–F10

## Сделано
- Вкладка «SSH Terminal» между SSH Files и History (`MainWindow.xaml`).
- `SshTerminalView` / `SshTerminalViewModel`: одно подключение, `CreateShellStream("xterm", 120, 40, …)`, чтение в `DataReceived`, запись в `Task.Run`. Enter шлёт строку, Ctrl+C — `\x03`, вверх/вниз — история команд. Очистить сбрасывает экран.
- ANSI (цвета, курсор, `ESC ( B`) применяется в экранный буфер, в текст коды не попадают.
- Пароль по хвосту «password:» / «пароль:» через `SshRunner.AskSudo` → `SudoMemory.Ask`. В вывод подставляется пусто, в журнал строка с паролем не пишется. Точка `AskSudo` в `SshRunner.cs` — `Ask` был приватным.
- SSH Files: убраны нижняя консоль, splitter и кнопка Terminal. Строка `LastOperation`. F3 — окно только для чтения, до 1 МБ (`SftpBrowser.ReadHead`, файл не из списка задачи: частичное чтение иначе качает файл целиком). F9 переключает на терминал с тем же хостом. F1 — список клавиш. F5 и F10 неактивны без подключения; F3/F4/F6/F7/F8 — если активна удалённая панель и нет подключения.

- Окно F3 и клики по панели в этой проверке не открывались.
