## Найдено и исправлено по ходу

- **Строка состояния после «Закрыть доступ» показывала «хост 1 из 1» вместо итога.** Ядро шлёт последний прогресс в `finally`, `Progress<T>` доставляет его после итога. Было и у «Добавить пользователя». После окончания запуска статусы из прогресса не берутся.
- **Заголовок окна не менялся на «Открыть доступ».** `UiDialog.Title` теперь меняется, `UiDialogs.Touch()` перерисовывает рамку.
- **Подтверждение «Убрать» в базовых пользователях** вторым окном пересоздало бы окно списка (DialogHost показывает только верхнее). Сделано внутри окна.

## Ревью Cursor

- **API.** `ApiJobs` берёт только встроенные ReadOnly — свои действия через API не идут.
- **Защита Destructive / ReadOnly** — и при сохранении, и в `LoadCatalog`.
- **Права** проверяются и на сервере (`Allowed(Vcenter)`), не только в кнопке.
- **Слияние:** `DialogHost` и `ActionsTab` пересекались с моими правками — слиты вручную; остальное — патчем.
