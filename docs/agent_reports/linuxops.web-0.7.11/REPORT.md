## Что сделано

Пара ed25519 создаётся на сервере службы (`ssh-keygen`), в браузер уходит только открытый ключ. «Применить» дописывает строку текущим доступом, проверяет вход новым ключом, затем пишет секрет и снимает прежнюю строку ключа службы. Расписания нет, мастер-ключ не меняется. Файл с диска по-прежнему только в хранилище.

## Требует ручной проверки

- Снятие старой строки проверено только для ed25519. Другой тип ключа, если отпечаток строки не совпадёт, останется с текстом «старый публичный не снят».
- На чистом дереве `tools/package-linuxops-web.ps1` останавливается: в `guacamole-common.min.js` один лишний CR в конце, закреплённый SHA-256 считается без него. Для сборок CR убран на время упаковки и файл возвращён как в git. Пин и файл не менял.
