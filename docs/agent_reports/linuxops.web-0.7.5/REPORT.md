## Замечания

- Хост без логина в дереве показан как «@адрес» — логин задаётся «Учёткой SSH…».
- Файл из Excel не в UTF-8 (1251) — отказ с подсказкой «CSV UTF-8».

## Inventory — только админы (по замечанию владельца)

Право «Inventory» — только у встроенной «Админ» и только из назначения на «всё» (как vCenter); из «Оператора» убрано, в своих ролях недоступно. Вкладка — только у кого оно есть.
