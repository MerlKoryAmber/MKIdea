# LinuxOps 0.3.51 — «Обновить отмеченное» из таблицы «Версии ПО»

Дата: 2026-11-20 (МСК).

## Задача
Владелец: «как сделать, чтобы из этого списка, проставив галки, запустить обновление?». Предложенный план принят («Да, делай»):
- галки только у пакетов хоста с доступным обновлением;
- предпросмотр → подтверждение → установка только отмеченного (и пакетов той же сборки);
- службы со старыми файлами — показать, перезапуск по выбору;
- после установки — повторная проверка.

## Изменения
- **`Services/PackageUpdate.cs`** (новый):
  - скрытое действие `update-selected` (параметры `UPD_PKGS`, `UPD_VIA_PC`; destructive, тайм-аут 30 мин):
    - к отмеченным добавляются пакеты той же сборки — rpm `SOURCERPM`, dpkg `source:Package`;
    - имена пакетов проверяются по допустимым символам;
    - предпросмотр (`LINUXOPS_DRY=1`) — dnf `--assumeno`, apt `-s`, zypper `--dry-run`, разбор в строки `P` (раздел, пакет, версия), `NOTHING`, `ERR`;
    - установка — `dnf -y upgrade`, `apt-get -y install --only-upgrade` (confold), `zypper -n update`; затем версии после (`NOW`) и службы со старыми файлами (`RESTART`);
  - скрытое действие `restart-services` (`UPD_SVCS`): `systemctl restart`, для sshd — сначала `sshd -t`;
  - `PackageUpdateReport`, `RestartReport` — разбор и текст для «Деталей» и History.
- **`PlanRunner`**:
  - туннель вынесен в `Tunnel.OpenIfAsked` и работает для «Версий ПО» и обновления, в том числе в предпросмотре;
  - разбор строк обновления и перезапуска;
  - `MakeRow` сохраняет отчёт в строке DRY-RUN.
- **`VersionItem`** — `IsChecked` (с уведомлением), `CanUpdate`.
- **`ActionsView` / `ActionsViewModel`**:
  - столбец галок;
  - панель «Отметить безопасности», «Обновить отмеченное (N)», «через этот ПК (туннель SSH)»;
  - сценарий `UpdateSelected`: предпросмотр → `AppDialog.Confirm` со списком → установка → окно перезапуска (`PsRunWindow` с галками по службам) → повторная `versions-check`;
  - при отмене выбор возвращается на исходную проверку;
  - окно перезапуска: сначала службы продуктов, системные — блоком с одним пояснением (ActionParam.Group, Hint = "-").

## ✅ Проверено
- **Скрипт на лабе, предпросмотр** (хост, ничего не ставилось): php-fpm и openssl → 12 пакетов (php-common, php-cli…, openssl-libs, openssl-fips-provider), версии из репозитория, 1 с.
- **Установка — во временных контейнерах на лабе**; хост не трогался, контейнеры и образы потом удалены:
  - Rocky 9.2: предпросмотр openssl (с зависимостью), установка (`RC 0`, `NOW openssl 3.5.9`), повторный предпросмотр — «обновлять нечего»;
  - Debian 12.0: libc6 + tzdata → libc-bin добавлен как пакет той же сборки, предпросмотр и установка (`NOW libc6 2.36-9+deb12u14`).
- **Поиск служб со старыми файлами:**
  - на хосте лабы (только чтение) сначала было ложное срабатывание на `/dev/zero (deleted)` у nginx и php-fpm — исправлено: считаются только файлы из /usr, /lib, /bin, /sbin, /opt;
  - положительный случай — временная служба `lo51-test` (копия sleep, файл удалён) найдена ровно она; служба и файл убраны.
- **Скрипт перезапуска:**
  - несуществующая служба — строка «ошибка» с текстом systemctl;
  - sshd в контейнере без ключей хоста — «пропущена: проверка sshd -t не прошла».
- **Через программу (Debug, лаба):**
  - галки видны только у 6 пакетов с обновлением;
  - кнопка «Обновить отмеченное (1)» после галки у php-fpm;
  - предпросмотр — DRY-RUN «поставится пакетов: 8»;
  - окно подтверждения со списком PHP (снимок);
  - «Отмена» — таблица снова на экране, галка сохранилась, на лабе php-fpm 8.0.30-8 и openssl 3.5.8 как были;
  - с галкой «через этот ПК» туннель поднимается и в предпросмотре («Соединений через этот ПК: 0» — dnf ответил по неустаревшим спискам).
- **Release `dist\LinuxOps-0.3.51`** (копия): версия 0.3.51, тот же сценарий до окна подтверждения и «Отмена» — работает. Пересобрана после правки окна перезапуска. На уже обновлённой лабе — «замечаний нет», панель «Обновить отмеченное» скрыта, потому что обновлять нечего.
- **Настоящая установка на лабе через программу, с галкой «через этот ПК»** (владелец: «это ж лаба — там можно делать всё»):
  - openssl + php-fpm — 12 пакетов. Перезапуск не дошёл: тест искал окно не там, при остановке теста закрылась и программа. Пакеты встали: php-fpm 8.0.30-9, openssl 3.5.9.
  - httpd-core + openssh-server — 8 пакетов, 10 соединений через ПК (mirror.netone.nl:80 ×8, mirrors.centos.org:443 ×2). Окно перезапуска — 13 служб со старыми файлами, отмечен только nginx (снимок); nginx перезапущен. sshd пакет перезапустил сам — его в списке нет. Повторная проверка — «обновлений: 1».
  - python3 — 4 пакета, 5 соединений через ПК. Окно перезапуска в новом виде: системные службы одним блоком, без отметок (снимок). Ничего не отмечено — перезапуск не запускался. Повторная проверка — «замечаний нет».
- Сборка Debug и Release — без ошибок.
