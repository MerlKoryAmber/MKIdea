# LinuxOps 0.3.32 — пароль зашифрованного ключа SSH

Дата: 2026-11-05 (МСК).

## Задача
Хост с зашифрованным ключом не подключался: «Private key is encrypted but passphrase is empty». Владелец: пароль ключа запрашивать при подключении и хранить до закрытия приложения.

## Изменения
- `Services/SshAuth.cs` — `KeyPassphrases`: загрузка ключа без пароля; при `SshPassPhraseNullOrEmptyException` — запрос через Dispatcher, кэш в памяти по полному пути ключа, до 3 попыток, общий замок (параллельные хосты — один запрос).
- `SudoPasswordWindow.xaml.cs` — второй конструктор (заголовок, подсказка) для запроса пароля ключа.
- `SudoPasswordWindow.xaml` — высота по содержимому (`SizeToContent`): со строкой ошибки поле ввода обрезалось.
- `HostEditWindow.xaml.cs` — «Проверить подключение» в `Task.Run`: раньше подключение в UI-потоке взаимно блокировалось с окном доверия ключу хоста (`Dispatcher.Invoke`).

## ✅ Проверено автоматически
- `dotnet build`: 0 ошибок, 0 предупреждений.
- Harness на SSH.NET 2026.0.0: ed25519, RSA OpenSSH, RSA PEM, ECDSA — без пароля `SshPassPhraseNullOrEmptyException`, неверный `SshException`/`CryptographicException` (перехватываются), верный — OK; ключ без пароля — без запроса; `BuildAuth` без UI — понятная ошибка.
- UI (UI Automation, без SendKeys): окно «Пароль ключа SSH»; неверный пароль → повтор с «Неверный пароль ключа.»; верный → окно доверия ключу хоста → «Подключено. CentOS Stream 9 (centos)» на лабе 192.168.0.178 (временный ключ `linuxops-test-enc-key` в `authorized_keys` root, удалён после теста); второе подключение — без запроса пароля ключа; приложение не зависает.
- Скриншот окна с ошибкой после правки высоты — поле ввода целиком.

## 👀 Требует ручной проверки
- Вход на NLProxy вашим ключом (на лабе проверено тестовым).

## Инциденты
- Первый UI-тест через SendKeys ввёл тестовые пароли (одноразовые, локальные ключи) в окно чата владельца. Тест переписан на UIA-паттерны без ввода с клавиатуры.
- Первая попытка добавить тестовый ключ на лабу отклонена проверкой безопасности Claude Code; после явного согласия владельца ключ добавлен на время теста и удалён.
