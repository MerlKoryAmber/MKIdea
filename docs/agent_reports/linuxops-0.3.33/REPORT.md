# LinuxOps 0.3.33 — компактный каталог, аудит пользователей с ключами

Дата: 2026-11-05 (МСК).

## Задача
Убрать надпись «В плане» у галки и подсказку над каталогом (съедают место); в аудите прав показывать ключи SSH; список пользователей — не консольным текстом, а в GUI.

## Изменения
- `Views/ActionsView.xaml` — галка без текста (ToolTip «В плане»); строка-подсказка удалена, «Новое» в заголовке каталога; в «Деталях» — карточки учёток и кнопка «Текст/Таблица».
- `Services/UserAudit.cs` (новый) — скрипт (строки U/K/S через таб), разбор, сводка, текстовый вид.
- `Services/BuiltinActions.cs` — list-users берёт скрипт из `UserAudit`, новое описание.
- `Services/PlanRunner.cs` — для list-users строка результата с разобранным отчётом (`ResultRow.Audit`), сводка в превью, текст в Detail/History.
- `ViewModels/ActionsViewModel.cs` — `DetailAudit`, `ShowRawDetail`, `ToggleDetailView`.

## ✅ Проверено автоматически
- `dotnet build`: 0 ошибок, 0 предупреждений.
- Скрипт на лабе (CentOS Stream 9): root с 2 ключами; lo-audit — wheel → sudo, 2 ключа, строка с `from="…"` разобрана; lo-audit2 — `usermod -L` + `chage -E 0` → «заблокирован»; sync/shutdown/halt отфильтрованы.
- UI (UI Automation, без клавиатуры): Actions → план только «Аудит» → Dry-run → строка «учёток 3 · sudo 2 · ключей 4 · заблокировано 1»; карточки со значками sudo/заблокирован и ключами; «Текст» — текстовый отчёт. Скриншоты сняты.
- Тестовые учётки на лабе удалены (`userdel -r`).
