# LinuxOps 0.3.55 — PowerShell: скрипты в UTF-16 без BOM

Дата: 2026-11-27 (МСК). Ветка `feature/linuxops-web`.

## Задача
- Замечание владельца по вкладке PowerShell. Код из верхней части уезжал в консоль «через жопу», а `#` не воспринимался как комментарий — и при «Запустить», и при «Выделенное». Скрипт — `New-VeeamVCenterRole.ps1`.

## Причина
- Файл был в **UTF-16 LE без BOM**.
- `File.ReadAllText` читал его как UTF-8, и после каждого символа появлялся `\0`. Строки вида `#\0R\0e\0…` PSReadLine и парсер уже не считали комментарием.
- F5 тоже ломался: PowerShell 7 читает файл без BOM как UTF-8.

## Решение
- **`ScriptFile`** (`src/LinuxOps/Services`) определяет кодировку:
  - по BOM;
  - UTF-16 LE/BE без BOM — по нулевым байтам в чётных и нечётных позициях;
  - строгий UTF-8;
  - иначе — ANSI-кодировка системы.
  
  Символы `\0` из текста убираются.
- **`PsScript.UnreadableEncoding`.** Если PowerShell 7 сам файл не прочтёт, F5 запускает копию в UTF-8. Строка состояния говорит, в какой кодировке файл и что «Сохранить» перезапишет его в UTF-8 с BOM.
- **`PsConsoleView.SendLines`** отбрасывает `\0`, в том числе при вставке из буфера.
- **Файлы ключей** (окна доступа, «Добавить пользователя», список пользователей) читаются через `ScriptFile`.
- **Подсветка.** Цвет чисел в xshd называется `NumberLiteral`, поэтому в тёмной теме цифры оставались тёмно-синими. Исправлено; добавлены цвета `ExceptionKeywords`, `GotoKeywords`, `ReferenceTypes`.

## ✅ Проверено
Debug-сборка в scratchpad, управление через UI Automation, снимки экрана.

- **До правки.** Простые скрипты с `#` и `<# #>` (кириллица, табы, функции) — F5 и F8 работают, в том числе при русской раскладке. Значит, дело в файле.
- **После правки, копия скрипта владельца**, открыта через «Открыть»:
  - текст чистый, вкладка `veeam.ps1`;
  - строка состояния: «UTF-16 LE без BOM… F5 запускает копию в UTF-8»;
  - **F5:** PowerShell разобрал `#Requires -Modules VMware.VimAutomation.Core` и сообщил, что модуля нет (в песочнице нет PowerCLI);
  - **F8 на всём тексте:** многострочный ввод без мусора, дошло до запроса `VCenter:` (параметр Mandatory).
- **Числа** в тёмной теме читаются.
- **Release:** `dist\LinuxOps-0.3.55` (single-file, сжатый, 75 МБ), версия exe 0.3.55. Данные владельца перенесены из 0.3.54: defaults, history, users, known_hosts, кэш CVE.

## 👀 Не проверено
- **Скрипт на настоящем vCenter с PowerCLI.** В песочнице PowerCLI нет; проверено до запроса параметров.
- **Release-exe не запускался.** Код тот же, что в проверенной Debug-сборке.
