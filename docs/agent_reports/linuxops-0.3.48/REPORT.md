# LinuxOps 0.3.48 — клиент RDP выбирается пробным созданием

Дата: 2026-11-20 (МСК).

## Задача
Скриншот владельца с 0.3.47 на Windows 10 LTSC 2019: программа больше не закрывается, но во вкладке RDP пишет «Не удалось встроить клиент RDP: Требуемый класс отсутствует в ClassFactory (0x80040111 (CLASS_E_CLASSNOTAVAILABLE))».

## Разбор
`CLASS_E_CLASSNOTAVAILABLE` означает, что CLSID есть в реестре и DLL загрузилась, но её фабрика такого класса не знает. В 1809 запись `MsRdpClient10` в `HKCR\CLSID` есть, а `mstscax.dll` этой сборки её не реализует. Проверка 0.3.47 смотрела только реестр, поэтому выбрала 10 и не перешла на 9.

## Изменения
- **`RdpControl.Pick()`:**
  - перебор `MsRdpClient10` → `MsRdpClient9`;
  - для каждого — пробный объект (`Type.GetTypeFromCLSID` + `Activator.CreateInstance`), сразу `FinalReleaseComObject`;
  - выбирается первый созданный, выбор запоминается до закрытия программы;
  - пропущенные классы с кодами пишутся в `LinuxOps.crash.log` («RDP: выбран MsRdpClient9; не создаются: MsRdpClient10 (0x80040111)»);
  - не создаётся ни один — ошибка во вкладке с кодами.
- Debug-переключатель `LINUXOPS_RDP_CLASS` теперь подменяет список кандидатов: `broken` — «10» не создаётся, `none` — не создаётся ни один, `9` — только 9.
- Текст при сбое встраивания: «В этой Windows не создаётся клиент RDP … (mstscax, 0x…)» для 0x80040154 и 0x80040111.

## ✅ Проверено
Через программу на dc-01, машина не в домене:
- **«10 не создаётся»** (Debug, `broken`):
  - выбран 9, вход по паролю, статус «dc-01 · merl@merl.loc · Обычный…», отключение;
  - после изменения размера окна новых окон ошибки нет;
  - запись в журнале «выбран MsRdpClient9; не создаются: MsRdpClient10 (0x80040154)».
- **Клиент 9:**
  - RCG — окно ошибки клиента (без Kerberos), статус с подсказкой, программа работает;
  - Restricted Admin — «Сервер закрыл подключение до входа · …».
- **Не создаётся ни один** (`none`) — во вкладке причина с кодом, программа работает.
- **Штатный клиент 10:** вход по паролю, отключение.
- **Release `dist\LinuxOps-0.3.48`:**
  - версия 0.3.48;
  - RCG — как выше;
  - выбран 10, журнал не создан (пропусков не было).
- Сборка — без ошибок.

## 👀 Не проверено
- **Windows 10 LTSC 2019 у владельца.** Ожидается клиент 9: подключение во вкладке, в `LinuxOps.crash.log` — строка «выбран MsRdpClient9». Отличие клиента 9 от 10 для программы — только класс: свойства и методы, которые она использует, одинаковы.
- Ревью не автором не проводилось.
