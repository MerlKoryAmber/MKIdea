# LinuxOps 0.3.35 — базовые пользователи из аудита

Дата: 2026-11-05 (МСК).

## Задача
Добавлять в базовые пользователи тех, кого нашёл аудит в текущей сессии, если у них есть вход по ключу, — с выбором.

## Изменения
- `UserListWindow.xaml(.cs)` — кнопка «Из аудита» в «Взять с хоста»; сбор кандидатов из отчётов аудита (UID ≥ 1000, есть ключи, не заблокирован), ключи без опций, sudo по любому хосту, отметка уже имеющихся; `ImportRow.Note`.
- `Services/UserAudit.cs` — флаг опций у строки ключа (`AuditKey.HasOptions`).
- `ViewModels/ActionsViewModel.cs` — отчёты аудита передаются в окно базовых пользователей.

## ✅ Проверено автоматически
- `dotnet build`: 0 ошибок, 0 предупреждений.
- Лаба, UI Automation без клавиатуры: 4 временные учётки → аудит → «Базовые пользователи (1)» → «Взять с хоста» → «Из аудита»: lo-b1 [вкл] sudo, 1 ключ; lo-b2 [выкл] «уже в базовых с этими ключами»; строка «Пропущено — ключей с опциями: 1, заблокированных учёток: 1». «Добавить отмеченных» → в `LinuxOps.users.json` lo-b1 (Sudo=true, только ключ без `from=`, «из аудита: lab-centos»), lo-b2 не задублирован.
