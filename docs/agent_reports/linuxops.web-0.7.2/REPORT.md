# LinuxOps Web 0.7.2 — пожелания владельца и находки проверки Cursor 0.7.1

Дата: 2026-11-22 (МСК). Ветка `feature/linuxops-web`. План — `docs/linuxops/PLAN-web.md`, «Доработки — 0.7.2», решение 18.

## Задача
- Пожелания: настройки — боковое меню; RDP — показать подстановку домена; «Парк» — отдельной вкладкой и узкая колонка хостов.
- По ходу:
  - «Парк» → Vulnerabilities, «Подключения» → Connections;
  - у Vulnerabilities своё право;
  - колонка «Продукт» — по содержимому;
  - README и инструкция по установке.
- Находки независимой проверки 0.7.1 (`docs/agent_reports/linuxops.web-0.7.1-verify/REPORT.md`).
- Решение 18: проверка зависимостей — шаг каждого релиза. SQLite и .NET внутри сервиса, `dnf` их не обновляет.

## Решение
- **SQLite:** `SQLitePCLRaw.bundle_e_sqlite3` 2.1.14 явно, `Microsoft.Data.Sqlite` 8.0.34. На стенде `libe_sqlite3.so` — 3.54.0 (было 3.41.2).
- **.NET 8.0.34 внутри сборки:**
  - SDK на ПК — 8.0.425 с runtime 8.0.31, в Program Files без админа не обновить;
  - поэтому версия закреплена в csproj: `LinuxOpsRuntimePatch` → `KnownFrameworkReference.LatestRuntimeFrameworkVersion` в цели перед `ProcessFrameworkReferences`, пакеты среды берутся с NuGet;
  - `System.Private.CoreLib.dll` и `Microsoft.AspNetCore.Http.dll` в сборке — 8.0.34.
- **Скрипт сборки** (`tools/package-linuxops-web.ps1`):
  - `dotnet list package --vulnerable --include-transitive --format json` — нашёл уязвимое, сборка останавливается (обход `-AllowVulnerable "причина"`);
  - версия .NET из `runtimeconfig.json` сверяется с `releases.json` Microsoft;
  - SHA-256 `guacamole-common.min.js` сверяется с `SOURCE.txt`. sha512 архива npm без скачивания архива не сверить, поэтому закреплён хэш самого файла.
- **Права:**
  - `TestConnect` и `TestRdpPort` → `CanTestHost`: право Inventory на хост, для нового — на папку;
  - `ToggleFolder` — только своя видимая папка, своя копия объекта;
  - `GuacTickets.Take` и `FileDownloads` — `TryGetValue` → сверка логина → `TryRemove(KeyValuePair)`.
- **`Perm.FleetView`** (`fleet.view`):
  - встроенные: «Админ», «Оператор», «Аудитор»;
  - свои роли с `hosts.view` получают его один раз (`GrantFleetView`, флаг `perm_fleet`);
  - вкладка — `Can`, строки — `CanOn` на хост.
- **`FleetCheck.RunNow(pressedBy)`** — проверка от «расписание», нажавший — запись «проверка уязвимостей: запущена вручную».
- **Интерфейс:**
  - `SettingsTab` переписан на разделы (`Sections`, `sessionStorage`), роли и назначения — `RightsBlock`;
  - `FleetTab.razor` — новая вкладка; режим Fleet из `HistoryTab` убран; снимок хранит все номера CVE;
  - `TerminalTab` — подсказки домена, `WebSession.SplitRdpLogin` и `RdpLoginPreview`;
  - CSS для узкого окна — в конце `app.css`. **Найдено на проверке:** сначала блок стоял выше основных правил и не действовал.
- **Документы:** `docs/linuxops.web/README.md`, `INSTALL.md`, `API.md`.

## ✅ Проверено
Стенд 192.168.0.169, перед каждой выкладкой — `linuxops-web backup`. Сборка Release — 0 предупреждений, 0 ошибок.
- **Скрипт сборки:**
  - «Уязвимых пакетов нет»;
  - на пробном проекте с `Microsoft.Data.Sqlite` 8.0.11 разбор нашёл `SQLitePCLRaw.lib.e_sqlite3 2.1.6: High GHSA-2m69-gcr7-jv3q`;
  - .NET 8.0.31 → предупреждение; после закрепления — «8.0.34 — последнее исправление»;
  - guacamole — «SHA-256 совпал».
- **Стенд:** версия 0.7.2, служба, nginx и guacd active; в `runtimeconfig` — 8.0.34; SQLite 3.54.0. В журнале «fleet.view granted to 2 custom roles», флаг `perm_fleet=1`.
- **Настройки (admin, 1280):**
  - все 8 разделов открываются;
  - «Сохранить AD и сессию», «Проверка уязвимостей → Сохранить», «Записи сеансов → Сохранить» — сообщения о сохранении;
  - роль: копия «Оператора» → «Сохранить роль» → «Удалить» — создалась и пропала;
  - после F5 открыт тот же раздел («Права»);
  - lo-dept-test (без права «Настройки») — только тема, меню нет.
- **«Проверить сейчас»:**
  - строка запуска «2026-11-22 14:47 · расписание · проверено 2 из 2»;
  - в аудите `admin … проверка парка: запущена вручную` (до переименования), затем «расписание … начата / итог».
- **Vulnerabilities:**
  - вкладка в шапке, у vm-188 все 8 номеров CVE с переносом, тёмная и светлая темы;
  - 1280: «Продукт» 206 px, CVE — остальное; 1000: список хостов над деталями, ширина страницы 1000;
  - lo-dept-test видит только vm-188 — lab-178, где у него «Просмотр», скрыт.
- **Ширина 1000 (Actions):** `scrollWidth` 1000, «Копировать» right 975, «Применить» right 988; шапка в одну строку. На 1280 шапка тоже в одну строку.
- **RDP** (lo-dept-test, временный хост `tmp-rdp-test` 192.0.2.10 в «Отдел Б»):
  - «Проверить порт» для нового хоста в своей папке — «192.0.2.10:3389 не ответил за 3 с», отказа по праву нет;
  - в форме: подсказка «логин — домен merl.loc подставится сам»;
  - по мере ввода: «войдёт как merl.loc\lo-dept-test», `.\localadm` → «войдёт как локальная учётка хоста: localadm», пустое поле → подсказка про другой домен;
  - вход с фиктивным паролем → аудит `RDP: вход tmp-rdp-test: учётка merl.loc\lo-dept-test`;
  - хост удалён. dc-01 не трогал.

## 👀 Не проверено
- Отказы «Проверить подключение / порт» на чужом хосте, раскрытие чужой папки, чужой пропуск — из интерфейса до них не добраться (окно хоста открывается только при праве), прямого вызова метода нет. Проверено чтением кода.
- Экран уже 960 px: у приложения минимальная ширина 960, ниже — горизонтальная прокрутка, как и раньше.
- Лимит 429 — не перепроверял: по аудиту стенда причина в SKIP на занятом хосте, это не ошибка.
