# 0.3.21 — F4, правка удалённого файла

## Сделано
- Настройка `F4Editor` в `LinuxOps.defaults.json`, по умолчанию `notepad.exe`. Кнопка «Редактор для F4» над панелью клавиш (кнопка в `Views/SshFilesView.xaml` — список правок иначе некуда поставить). Поле — в `Models/AppModels.cs`.
- `RemoteEditSession`: каталог `%TEMP%\LinuxOpsEdit\<хост>\<хэш>\<имя>`, слежение LastWrite/Size/FileName (Changed, Created, Renamed), пауза 500 мс, чтение без чужой блокировки, SHA256. Вопрос: «Сохранить», «Не сейчас», «Сохранять без вопроса для этого файла».
- Конфликт по размеру или времени сервера: «Файл на сервере изменился после открытия», перезаписать или отменить.
- Запись, если в папку можно писать и sudo не выбран: `<путь>.linuxops.tmp`, posix-rename, права и владелец как были. Иначе (и при режиме sudo): `/tmp/linuxops-edit-<случайное>`, затем `cp --preserve=mode,ownership` в `.linuxops.bak` и `cat` на место. Для `/etc/sudoers` и `/etc/sudoers.d/*` перед заменой `visudo -cf`; при ошибке файл не меняется.
- Файл 600, который SFTP не читает, для F4 копируется через sudo во временный и забирается оттуда.
- Журнал: путь, хост, размер, результат. Содержимого нет.
- Отключение и смена хоста спрашивают про несохранённые правки.
