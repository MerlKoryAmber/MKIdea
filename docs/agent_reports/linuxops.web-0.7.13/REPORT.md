## Найдено и исправлено

**Удаление хоста оставляло в `settings` записи `keyat:<id>` и `keyerr:<id>`.** Вреда нет, но это мусор в базе.

Теперь `WebStore.DeleteHost` удаляет их вместе с `keyname:`. Проверено на 0.7.13: временный хост `del-test` получил обе записи, удалён через Inventory — записей нет. Записи `keyname:` других хостов не тронуты. Старые сироты от `keytest-188` удалены вручную.

## Убрано за собой

- Срок снова пустой («не менять»).
- Хосты `keytest-188` и `del-test` удалены из Inventory.
- Учётная запись `lo-keytest` удалена на vm-188 (`userdel -r`).
