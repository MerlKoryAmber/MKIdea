# LinuxOps 0.3.15

Статус: РЕАЛИЗОВАНО НО НЕ ПРИНЯТО.

## Правки

- `sudo -n true` всегда до пароля. Пароль в stdin только если sudo его просит.
- Скрипт учётки падает с текстом на ошибке шага и не печатает `created=yes`. Группа каталога — `id -gn`. SUSE: `/etc/sudoers.d`, не wheel.
- Кэш sudo — `ConcurrentDictionary`. «Стоп» отменяет текущую SSH-команду.
- Футер только на Actions. Линия Inventory цветом темы, без чёрной рамки строки. Свои ComboBox. Пустой статус передачи в SSH не раздвигает правую шапку.

## Проверки

- `dotnet build -c Release -warnaserror` — 0/0.
- `dist\LinuxOps-0.3.15\LinuxOps.exe`, окно 1280×780: Inventory, SSH Files, History без нижней полосы. Списки белые. Заголовки колонок SSH на одной высоте. Под строкой Inventory светлая линия темы, не чёрная.
- Лаба `192.168.0.178`: несуществующая группа → `нет группы …`, exit 1, без `created=yes`, учётка удалена. Режим файла sudoers: `created=yes` / повтор `already`, строка в sudoers.d, затем пользователь и файл удалены.
