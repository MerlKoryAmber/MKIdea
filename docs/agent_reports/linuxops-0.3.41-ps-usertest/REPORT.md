# LinuxOps 0.3.41 — пользовательское тестирование вкладки PowerShell

Дата: 2026-11-16 (МСК). Сборка: `dist\LinuxOps-0.3.41` (копия в scratchpad), тёмная тема.
Как: UI Automation + настоящие нажатия клавиш (текст — посимвольно, как с клавиатуры, кириллица тоже), мышь для выделения; ввод только при окне LinuxOps на переднем плане. ~45 сценариев, 6 прогонов, снимки экрана.

## Работает
- Запуск движка 1,6–2,1 с; набор команд с клавиатуры, кириллица в командах и выводе.
- История ↑/↓, Esc очищает строку; `cd` меняет приглашение.
- Ошибки красным, у F5 — с номером строки и подчёркиванием; скрипт после ошибки продолжается.
- Большой вывод: `1..20000` — 1,2 с, окно отвечает; бесконечный цикл с выводом — «Стоп» за 0,5 с; Ctrl+Break — 0,6 с.
- Write-Progress — в строке состояния справа («Копирую: 14 из 20 — 70%»).
- Read-Host (ввод с клавиатуры, кириллица), Get-Credential, `pause` — окнами LinuxOps.
- Таблицы подстраиваются под ширину: 347 колонок развёрнуто, 141 — в окне 1100 px.
- `exit` не ломает сеанс (переменные живы). Копирование из консоли (щелчок, Ctrl+A, Ctrl+C).
- Редактор: Ctrl+N — новая вкладка, F5, Shift+Home + F8, Ctrl+S → «Сохранить как» → файл UTF-8 с BOM, вкладка переименована; Ctrl+O открывает; «*» у изменённых; закрытие вкладки и программы с несохранённым — «Сохранить / Не сохранять / Отмена»; движок закрывается вместе с программой.

## Найдено (по важности)
1. **Вывод внешних программ пропадает**: `whoami`, `git --version`, `cmd /c echo …` (и stderr) — в консоли пусто. Видно только через переменную или конвейер (`$w = whoami`, `ipconfig | Select …`, `| Out-Host`). Для администратора это главное: `ipconfig`, `ping`, `nslookup`, `robocopy`, `netsh` «молчат».
2. **`[Console]::ReadKey()` вешает движок**: «Стоп» не помогает (40 с «остановка…»), спасает только «Перезапустить движок». Так же поведут себя скрипты с `[Console]::ReadLine()` / «Press any key».
3. **Out-GridView роняет движок** («Exception has been thrown by the target of an invocation», «движок PowerShell завершился»). Следующая команда поднимает новый движок, переменные теряются.
4. **`cls` / `Clear-Host` не очищают консоль** (работает только кнопка «Очистить консоль»).
5. **Tab в строке ввода** — нет дополнения, фокус уходит из поля.
6. **Ctrl+C во время выполнения** — ничего (останавливает только Ctrl+Break / «Стоп»); пользователи консоли жмут Ctrl+C.
7. **Shift+Enter** сразу выполняет строку — многострочную команду (`foreach (…) {` ⏎ …) в консоли не набрать.
8. **Редактор**: Ctrl+F — поиска нет; после `{` ⏎ нет автоотступа; Ctrl+Z отменяет по одному символу.
9. **Read-Host → «Отмена»** — скрипт молча обрывается, статус «завершено с ошибками», в консоли без пояснения.
10. **Start-Job** не работает в встроенном движке (сообщение PowerShell: «not supported … use ThreadJob»).

Не баги (проверено по снимкам): «двойные» ошибки в первом прогоне — артефакт чтения консоли через UI Automation, на экране одна.

## 👀 Не проверено
- Светлая тема, PowerCLI/vCenter, кнопка «vSphere…» — вне этого прогона.
- Причины п. 1–3 в коде не разбирались, кроме очевидного: п. 4 — `SetBufferContents` в `LoHost` пустой; п. 2 — у движка, судя по всему, нет консольного ввода, а `[Console]::ReadKey` ждёт его без отмены.
